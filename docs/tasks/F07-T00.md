# F07-T00 — Bounded tabular source reading

State: in progress

## Outcome

Controlled CSV/XLSX files become a bounded source table for staged import mapping, with no domain writes or formula execution.

## Prerequisites

[F00-T02](F00-T02.md). Split from F07-T01 before implementation because parsing and directory reconciliation are independently verifiable behaviours. PHP 8.4 zip, DOM and mbstring extensions are present locally; actual hosting extensions remain F10 evidence.

## Boundaries

CSV and ordinary XML-based XLSX source tables only, using installed PHP facilities without a new dependency. No legacy XLS, macros, formula calculation, external links, OCR, date/unit guessing or database mutation.

## Contracts

1. ReadTabularSource accepts a private UploadedFile and optional worksheet name. Return an allowlisted array with selected sheet, distinct non-empty header labels, list-of-string rows and original source record/worksheet row numbers. Preserve data values; adapters perform explicit domain/date/unit normalization later. Styles do not become policy.
2. Bounds: uploaded bytes at most 5 MiB; at most 64 columns and 1,000 non-empty data rows; each cell at most 8,000 characters. CSV is UTF-8 (optional BOM), comma-delimited with strict quoting, explicit empty escape argument and consistent row width. At least one non-empty data record is required; blank source records may be skipped. LF and CRLF record endings are supported. Reject invalid UTF-8, null bytes, duplicate/empty headers, malformed quoting or inconsistent columns.
3. XLSX uses ZipArchive without extraction and DOM with non-network XML parsing. Check archive entry count (2,000) and declared aggregate expansion (20 MiB), then read individual XML parts with a 2 MiB cap. Reject DTD/entity declarations, encrypted/invalid entries, macros and external workbook relationships. Only ordinary worksheet/shared-string/workbook relationships are interpreted.
4. Require an explicit sheet name for multi-sheet workbooks; default the sole sheet. Support shared strings, inline rich text, literal strings, numbers and booleans with empty sparse cells. Reject formula/error cells, duplicate/out-of-order coordinates, references beyond bounds and unsupported cell types. Do not follow hyperlinks or external resources. Dates remain literal values; adapters require an explicit date representation rather than infer spreadsheet formatting.
5. Errors expose file/row/sheet diagnostics without dumping raw source contents. Parsing has no database, public storage or network side effects. Authentication, staging, provenance, current scope and apply remain F07-T01 and later adapters.

## Acceptance criteria

- Well-formed CSV and selected XLSX sheets return intended headers/scalar values, including quoting, Unicode, rich/shared strings and sparse cells.
- Malformed/oversized/unsupported sources, formulas and external/DTD references fail before domain mutation.
- Reproducible generated CSV cases round-trip through native quoting, with retained explicit edge cases.
