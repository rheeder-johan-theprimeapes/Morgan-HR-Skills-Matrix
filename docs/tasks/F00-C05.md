## Outcome

## Boundaries

TestCase's existing post-configuration/pre-provider hook, database-free child-process tests and relevant quality records. No production configuration or package changes.

## Contracts

PHPUnit's forced environment settings do not replace an inherited `$_SERVER` entry, which Laravel reads first. After the database guard succeeds and before providers register, install fixed test configuration for mail=array, cache=array, queue=sync, session=array, broadcasting=null, file maintenance, the public test-only app key, bcrypt rounds=4 and disabled optional instrumentation. Preserve original DB identity capture and inherited APP_ENV=production refusal. Explicit alternative service connections remain the responsibility of a test's targeted fake; this contract secures ordinary defaults.

## Acceptance criteria

- Both actual XML profiles boot with inherited smtp/redis service selectors yet expose only the intended safe default configuration. Successful MySQL child coverage runs only under the explicitly selected MySQL profile; normal SQLite requires no private MySQL setup.
- The child probes resolve configuration only; they never connect to mail/cache/queue/session/database services or run migrations.
- The guard still rejects an inherited non-test environment, inherited DB identities and unsafe schemas before provider registration.
- Seed selection, production configuration and private files remain unchanged.
