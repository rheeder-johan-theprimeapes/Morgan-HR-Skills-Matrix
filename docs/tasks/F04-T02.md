4. Run focused/full isolated profiles, analysis/Pint/build and independent F04 review. Resolve review findings before review-workflow implementation.

## Acceptance criteria

- Valid metrics/context retain source, period, units and author; corrections preserve prior evidence.
- Forbidden actors cannot view/change restricted context or supply another person's identity.
- Missing/overlapping/incompatible periods are flagged; operational changes do not alter calculated skill points.
